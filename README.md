# Imposto_de_Renda_Reclame_Aqui

Este repositório contém a documentação e o desenvolvimento do projeto prático proposto pela **DIO** (Digital Innovation One), cujo objetivo é criar uma ferramenta avançada em Excel para auxiliar na organização, controle e validação de informações essenciais para a declaração de imposto de renda.

---

## 🎯 Sobre o Desafio

O desafio consiste em desenvolver um **Agregador de Dados** robusto, prático e com uma interface amigável utilizando recursos avançados do Excel. A ferramenta foi estruturada para centralizar o controle de entradas financeiras e dados relevantes, garantindo consistência através de validações automáticas e facilitando a navegação por meio de menus interativos e links rápidos.

### 🧠 Objetivos de Aprendizagem
* Aplicar conceitos avançados de planilhas eletrônicas em um cenário real e prático.
* Desenvolver uma interface limpa, intuitiva e funcional para o usuário final.
* Estruturar documentação técnica clara e profissional utilizando o Markdown.
* Utilizar o **GitHub** para versionamento e compartilhamento de portfólio técnico.

---

## 🛠️ Tecnologias e Recursos Utilizados

* **Microsoft Excel:** Ferramenta principal para construção da planilha, estruturação de tabelas, fórmulas, validação de dados e menus de navegação.
* **GitHub:** Plataforma de hospedagem de código e portfólio para o versionamento da documentação.
* **Markdown:** Linguagem de marcação utilizada para a elaboração deste `README.md`.

---

## 📋 Funcionalidades da Ferramenta

1. **Menu de Navegação Intuitivo:** Estrutura organizada com botões e links rápidos para facilitar o acesso rápido entre as abas e seções da planilha.
2. **Controle e Agregação de Entradas:** Módulo centralizado para registrar e monitorar dados financeiros e informações cadastrais.
3. **Validações Automáticas:** Aplicação de regras de validação de dados para evitar inconsistências e erros de digitação.
4. **Links Rápidos:** Atalhos úteis integrados à planilha para agilizar a consulta de informações de apoio.
